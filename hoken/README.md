# もしもシート（保険の整理）

入っている保険（民間・公的・会社の制度）を1か所に整理して、
**自分に何かあった時に家族のお金がどうなるか**を年ごとのグラフで見えるようにするアプリです。

`hoken/index.html` をブラウザで開くだけで動きます。サーバーもビルドも不要で、
データは端末のブラウザ（localStorage）に保存されます。

GitHub Pages を有効にすれば `https://<ユーザー名>.github.io/heart-salon/hoken/` として使えます。

要件の詳細と設計の判断は [REQUIREMENTS.md](./REQUIREMENTS.md) にあります。

## 画面

| タブ | 中身 |
|---|---|
| もしも | 一時金・毎月入るお金のサマリー／残高の推移グラフ／年ごとの収入と支出／前提のスライダー |
| 契約 | 入っている保険の一覧と追加・編集・詳細／会社の制度／年間保険料の集計 |
| 前提 | 自分と配偶者・子ども・住まい・暮らしのお金・資産・公的年金・教育費の補正 |
| 設定 | 閲覧用リンク／端末間の同期／JSONの書き出しと読み込み |

初めて開くと入力ウィザードが立ち上がり、7つの質問に答えると計算に必要な前提が揃います。
途中で「あとで」を押しても、そこまでの内容は保存されます。

## 契約の詳細を見る

一覧の「詳しく見る」を押すと、その契約の中身をまとめて読めます。
補償やサービスごとに、区分・項目名・説明・限度額・免責金額・対象外の項目が並びます。
閲覧モードでも開けるので、家族が「この保険で何がカバーされるのか」をその場で確認できます。

限度額に「要証券確認」「10万〜30万円程度」のように金額を1つに決められない記載があるものは、
**金額としては持たず、記載をそのまま文章で残しています。** 集計にも入りません。

## 用意してある契約データ

手元の台帳から起こした契約を `presets.js` に置いてあり、**開いたときに自動で取り込まれます。**
取り込んだ契約のidを覚えているので、台帳にあとから契約が増えても次に開けば入りますし、
一度取り込んだものを自分で消した場合は勝手に復活しません。

設定タブの「用意してある契約データ」から、取り込み状況の確認、手動での取り込み、
「台帳の内容で上書きする」ができます。上書きすると画面で加えた変更（ありかメモなど）は失われます。

台帳側（`presets.js`）の内容を直したときは `ledgerUpdatedAt` を新しくします。
アプリに入っている内容より台帳が新しいと、設定タブに「台帳が新しい」と表示されるので、
上書きして反映できます。

詳細画面に出していない項目（重複の可能性についての覚書など）も内部には保存してあり、
契約を編集して保存しても消えません。

## 家族に見せる

設定タブの「閲覧モードで開く」（URLの末尾に `#view` が付いたリンク）を家族に渡すと、
編集ボタンが表示されない状態で、もしもの時のサマリー・グラフと契約一覧だけが見られます。

同じ同期コード（合言葉）を入れた端末どうしで内容が同期されるので、
自分のPCで更新した内容がそのまま家族の画面にも反映されます。

**閲覧モードは画面上で編集ボタンを隠すだけの仕組みです。** データそのものを保護するものではありません。
誤操作を防ぐためのもの、と考えてください。

## 決めてあること（意図的な割り切り）

- **証券番号・口座番号・パスワードは保存しません。** 保存するのは「証券のありか」のテキストメモだけです。
  保険証券の写真添付も、番号が写り込むため入れていません。
- **税金は計算しません。** 死亡保険金の非課税枠も相続税も考慮せず、税引前の金額で表示します。
  民間の死亡保険にほとんど入っていない前提での割り切りです。
  まとまった額の死亡保険に入った場合は、この前提を見直してください。
- **公的年金は自動計算しません。** ねんきんネットなどで調べた年額を手で入れてください。
  金額が未入力のものは0として計算し、一覧に「未入力」と表示します。
- **収入保障保険の逓減は再現しません。** 「月額 × 12 × 支払期間」で単純に計算します。
- シミュレーション期間は既定で**配偶者が90歳になる年まで**です。前提タブで変更できます。

## 教育費の数字について

子どもの生年と進路から、年ごとの教育費を自動で割り当てています。内蔵している金額の出典は次のとおりです。

- 幼稚園〜高校 … 文部科学省「子供の学習費調査」の学習費総額
- 大学 … 日本政策金融公庫「教育費負担の実態調査」の在学費用・入学費用

**いずれも概算です。** 地域や学校で幅があるので、前提タブの「教育費の目安を補正する」から
段階ごとに上書きできます。上書きした行には「補正済み」と表示されます。空欄に戻すと元の概算に戻ります。

## 計算の中身

```
初期残高 = 「今すぐ使える」資産の合計

各年:
  入ってくるお金 = 死亡保険金（初年度）＋ 収入保障の月額×12
                 ＋ 会社の制度 ＋ 公的年金 ＋ 配偶者の収入 ＋ 資産の受取
  出ていくお金   = 生活費（削減率とインフレ率を反映）＋ 住居費 ＋ 教育費 ＋ 葬儀費（初年度）

  残高 = (前年の残高 + 入ってくるお金 - 出ていくお金) × (1 + 運用利回り)
```

- 生活費の削減率は、末子が独立する前と後で切り替わります（既定 70% → 50%）。
- 住宅ローンは、**団信に入っていれば死亡時の返済額を0**にします。管理費・固定資産税は残します。
- 残高がマイナスの年には運用利回りを掛けません。
- 残高が初めてマイナスになった年を「お金が尽きる年」として表示します。

計算のコードは `sim.js` にまとまっていて、画面のコードとは分かれています。

## ファイル構成

| ファイル | 役割 |
|---|---|
| `index.html` | 画面の骨格 |
| `app.js` | 画面の描画・入力・グラフ（SVGは自前で描画） |
| `sim.js` | もしもシミュレーションの計算（画面から独立した純粋な計算） |
| `data.js` | 保険の種類・保障の種類・教育費の目安などのマスターデータ |
| `presets.js` | 手元の台帳から起こした契約データ |
| `sync.js` | 端末間の同期（Firebase Firestore） |
| `style.css` | 見た目 |

金額は**すべて円で保存**しています。入力欄は項目に応じて万円で受け取り、保存前に円へ変換します。

## 同期とバックアップ

- 同期は `kintore` と同じく、同期コードのSHA-256をドキュメントIDにして共有する方式です。
- ただし統合の仕方が違います。保険のデータは追記型ではなく編集型なので、
  **`updatedAt` が新しい方で丸ごと上書き**します。上書きする前に確認ダイアログを出します。
- 上書きが不安なときは、先に設定タブからJSONを書き出しておいてください。
