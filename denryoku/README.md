# ⚡ 電力論述トレーナー

電験（電気主任技術者試験）二次試験の「電力・管理」を想定した、**論述問題**の学習アプリです。
ブラウザだけで動く単一ページアプリで、サーバーもライブラリも不要です。

`denryoku/index.html` をブラウザで開くだけで動きます。
GitHub Pages を有効にすれば `https://<ユーザー名>.github.io/heart-salon/denryoku/` としてスマホからも使えます。

## 機能

### 出題タブ

分野・細目・出題範囲で絞り込み、1問ずつ表示します（シャッフル可）。

1. 問題文だけを表示 → 頭の中（または紙）で答案を組み立てる
2. 「解答・解説を見る」で **押さえるキーワード → 模範解答 → 解説・書き方のポイント** を表示
3. 「📝 メモ」欄に気づきを書き残す（入力するそばから自動保存）
4. 「○書けた／△あいまい／×書けない」で自己採点

出題範囲は4種類から選べます。

| 範囲 | 出題される問題 |
|---|---|
| すべて | その分野・細目の全問 |
| 未学習 | まだ自己採点していない問題 |
| 苦手（△×） | △または×を付けた問題 |
| 復習おすすめ | 復習時期が来た問題（期日の古い順） |

復習時期は自己採点の結果で決まります。**× は1日後、△ は3日後、○ は14日後、2回目以降の○ は30日後**です。問題カードには「前回 3日前・2回目／次の復習 11日後」のように前回の学習状況が表示されます。

### 一覧タブ

全問をキーワード検索できます。問題文だけでなく模範解答・解説の本文も検索対象です。各項目には学習状態（○△×・未学習）と最終学習日、メモの有無が並び、タップするとその問題から出題を開始します。

### 記録タブ

- **サマリー**: 今日の学習数／連続学習日数／学習した日数／のべ学習回数。復習時期の問題があればバナーから直接その出題へ移動できます
- **学習カレンダー**: 直近12週間の学習量をヒートマップで表示
- **到達状況**: 全体と分野ごとの習得状況。分野をタップすると細目の内訳が開きます
- **メモを残した問題**: 書き込んだメモを新しい順に一覧。タップでその問題へ
- **学習履歴**: いつ・どの問題を・どう自己採点したかを新しい順に表示
- **データの管理**: 記録の書き出し／読み込み、全削除

## 学習記録の保存とバックアップ

学習記録（自己採点・履歴・メモ）は、端末のブラウザ内（localStorage、キー `denryoku-ronjutsu-v1`）にのみ保存されます。サーバーには一切送信されません。その代わり、次の場合は記録が消えるので注意してください。

- ブラウザの閲覧データ（サイトデータ）を削除したとき
- 別の端末・別のブラウザで開いたとき（記録は共有されません）
- プライベートブラウズで使ったとき

記録タブの「⬇️ 記録を書き出す」で `denryoku-record-YYYYMMDD.json` として保存でき、「⬆️ 記録を読み込む」で復元できます。読み込みは**上書きではなく統合**で、問題ごとに新しいほうの記録を採用し、履歴は重複を除いて時系列に結合します。同じファイルを二度読み込んでも履歴は増えません。端末間で記録を持ち運ぶときにもこの方法が使えます。

## 使い方のおすすめ

論述は「読んで分かる」と「書ける」の差が大きい科目です。解答を見る前に、**キーワードを3〜5個書き出してから**開くと効果的です。
解説には模範解答の内容そのものではなく、**答案の組み立て方・落としやすい観点・加点される一言**を書いてあります。

## 問題を追加する

`questions.js` の `questions` 配列に追加するだけで、アプリ側の変更なしに出題されます。

```js
{
  id: 'sub-01',                 // 一意なID（学習記録のキーになるので変更しない）
  field: '変電',                 // 発電 / 変電 / 送電 / 配電
  category: '変圧器',            // fields[].categories に定義した細目
  title: '変圧器の並行運転',       // 一覧に出る短い題名
  level: 2,                     // 1=基本 2=標準 3=応用
  question: '……について述べよ。',
  keywords: ['極性が一致', '%インピーダンス'],
  answer:  '■見出し\n本文\n\n■次の見出し\n本文',
  explanation: '書き方のポイント。**強調したい語**は ** で囲む。'
}
```

新しい細目を使うときは、同じファイル冒頭の `fields` の該当分野の `categories` にも追加してください。

### 本文の書式

- 行頭の `■` … 小見出しになります
- 空行 … 段落の区切り
- `**……**` … 強調表示（解説内でのポイント強調に使用）

## 出典について

問題文・模範解答・解説はいずれも、電験二種二次試験「電力・管理」で頻出の論述テーマをもとに、
このリポジトリ用に書き起こしたものです。特定の年度の過去問を転載したものではありません。
実際の出題年度・原文にあたる場合は、電気技術者試験センターの公表問題や過去問解説サイトを参照してください。
